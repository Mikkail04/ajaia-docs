# Product Brief: Ajaia Docs

## Problem

Teams draft shared work in scattered files and chat threads. We want **one place** to write, format and share a document.

## Goals

- Create and edit documents with *basic* rich text
- Import existing `.txt`, `.md` and `.docx` files
- Share with a teammate as an editor or a viewer

## Non-goals

1. Real-time cursors
2. Comments and suggestions
3. Version history

> Ship the smallest thing that feels coherent, then iterate.
